# 薪资计秒器 · 考勤日历

一个**单页**纯前端应用（HTML+CSS+JS），无后端依赖，开箱即用。集成薪资计算、考勤日历标注、请假管理与一键分享。

访问地址：`http://<本机IP>:8765/`

## 一、功能概览

### 1. 薪资计算（核心）— 含请假/迟到扣款与加班加薪
薪资输入为 **满勤收入**。系统按请假、迟到、加班实时计算实际到手与每秒收益：
- **扣款** = 满勤薪资 × (请假+缺席+迟到时长) ÷ 满勤工时（满勤工时 = 满勤应工作日 × 每日工时；法定节假日为带薪休息不计工时）
- **加班时薪** = 满勤薪资 ÷ 21.75 ÷ 7.5（法定月计薪21.75天 × 7.5h标准工时）
- **加班费** = 平时加班×1.5×时薪 + 休息日加班×1.5×时薪 + 法定节假日加班×3×时薪
- **实际到手** = 满勤薪资 − 扣款 + 加班费（保留两位小数）
- **每秒收益** = 实际到手 ÷ (实际工时 × 3600)，实际工时 = 满勤工时 − 缺勤时长 + 加班时长（六位小数）
- 加班输入区：平时/休息日/法定节假日 三栏，按月独立存储；**已移除输入框增减箭头**，数值完整可见
- 请假/迟到记录支持「时长（小时/天）」字段：留空按全天计；迟到填写实际迟到小时
- 实时薪资累积计时器按**实际到手**每秒累加（开始/暂停/重置）
- 当月出勤日历（七色标注）+ **薪资计算明细**（扣款/时薪/加班费/税前到手/五险一金/每秒收益，默认完全展开、不折叠）；**考勤明细**置于页面底部全宽展示，同样默认完全展开、不折叠
- **页面布局**：核心三件套（薪资输入 / 计算结果 / 实时薪资累积）首屏即见、无需滚动；五险一金与加班置于其下；右栏信息流为「计算结果 → 当月考勤日历 → 薪资计算明细」；底部为「考勤明细 → 请假/考勤记录」；计算结果面板不含五险一金列（五险一金在专属卡片配置）；核心卡片金色描边突出，次要卡片弱化；窄屏自动折叠单列并按逻辑重排

#### 五险一金扣除（可选）
- **⑥ 五险一金扣除**卡片提供启用/禁用开关，默认关闭
- 内置 **苏州 / 杭州** 两地 2025 年度最低缴费标准，通过「缴费地区」下拉切换：
  - **苏州**：基数 ¥4952，个人比例 养老 8% · 医疗 2% · 失业 0.5% · 公积金 5%，合计 **¥767.56/月**
  - **杭州**：社保基数下限 ¥4986（养老/医疗/失业同比例），公积金基数下限 ¥2490（最低工资，5%），合计 **¥648.03/月**
- 切换地区后四项金额自动套用该地区默认值，合计、实际到手、每秒收益、计算明细与数据来源文本**实时同步更新**
- 四项金额仍可手动修改；「↺ 重置为当前地区默认值」一键恢复所选地区的标准
- 计算明细在启用时新增 ⑧ 五险一金（标注地区）、⑨ 税后到手 两步；结果面板新增五险一金扣除行
- 设置随 localStorage 持久化，并随「🔗 分享」链接一同编码传出

### 2. 考勤日历标注（无审批流程）
- 点击「＋ 添加请假」按钮，或直接点击日历任一日期快速添加（自动预填该日期）
- 类型：9 种请假（事假/病假/年假/调休/婚假/产假/陪产假/丧假/其他）+ 2 种考勤异常（迟到/缺席）
- **无需审批，添加即生效**：请假/缺席落在工作日 → 扣减工作日并计入扣款；迟到仍计为出勤（仅扣迟到时长）
- **七色状态日历**：上班(青) / 迟到(橙) / 缺席(红) / 请假(紫) / 法定节假日(粉) / 调休上班(黄) / 休息(灰)，含清晰图例与考勤计算明细
- 记录支持编辑（回填）、删除、按类型/范围筛选、一键清空
- 数据 localStorage 持久化，刷新或重新访问不丢失（请假与各月加班数据分别存储）

### 3. 账户管理（多用户数据隔离）
- Header「👤 账户」按钮：未登录显示「登录」，登录后显示用户名
- **注册**：用户名 + 密码（≥4位）+ 确认密码，密码以**随机盐 + SHA-256 哈希**存储（非明文）
- **登录**：用户名 + 密码 + 「记住登录状态」选项（勾选存 localStorage 跨浏览器重启；不勾选存 sessionStorage 关闭标签即登出）
- **数据隔离**：登录后全部个人数据（设置默认值 / 五险一金 / 请假考勤 / 加班）自动路由到 `键名@用户名` 命名空间，不同用户互不干扰
- **首次登录迁移**：新账户若无名下数据，自动复制当前匿名数据，平滑过渡不丢失
- **登出**：切回匿名模式，匿名数据独立保留
- 未登录仍可匿名使用（向后兼容），账户为可选增强

### 4. 设置页签（默认值管理）
- 页面顶部「📊 计算 / ⚙ 设置」双页签切换
- 设置页集中管理**默认值**：本月满勤薪资、缴费省份→城市（二级联动）、每日工作时长
- 省市联动覆盖江苏省（苏州市）、浙江省（杭州市），与五险一金内置标准对齐
- 保存后刷新/重新访问自动套用到计算页；计算页临时修改不回写设置
- 「恢复出厂默认」一键回到 ¥10000 / 苏州 / 8h
- 数据 localStorage 持久化（`salary_settings_v1`），分享链接数据优先级高于设置默认

### 5. 一键分享（服务器令牌 + 时效/访问控制）

点「🔗 分享」将当前薪资设置 + 全部请假记录 + 各月加班数据生成**带时效的分享链接**发给朋友。链接形如 `http://<本机IP>:8765/#t=<令牌>`，数据由本地服务器托管（`serve.ps1` 内置 `/api/share` 接口），支持：

- **有效期**：1 小时 / 1 天 / 7 天 / 30 天 / 永久，到期后链接自动失效
- **访问次数上限**：1 / 3 / 5 / 20 / 不限，防止链接被未授权转发滥用（防滥用机制）
- **访问密码**（选填）：设置后打开链接需输入相同密码；密码以**随机盐 + SHA-256 哈希**存于服务器（非明文），同时用于数据 XOR 加密 —— 双重保护（服务器访问门禁 + 客户端数据加密）
- **可撤销**：「我分享的链接」列表管理所有已生成链接，可一键撤销，撤销后任何人都无法再访问
- **清晰错误提示**：链接无效 / 过期 / 已撤销 / 次数耗尽时，弹出对应说明并引导向分享者索取新链接
- **跨设备兼容**：链接仅含短令牌，在 Windows / macOS / Linux 的 Chrome / Firefox / Safari / Edge 上均可打开，功能与直接访问完全一致
- **服务不可用时自动降级**：若服务未运行，生成逻辑回退为 `#d=` 直链（数据编码在 URL，无时效/撤销，但仍可跨设备打开）

> 数据隔离：分享令牌存储在服务器端 `share-tokens.json`（仅含加密 payload + 密码哈希 + 元信息）；「我分享的链接」索引按用户命名空间存于 localStorage（`salary_myshares_v1`）。

**向后兼容**：旧版 `#d=` 直链（数据编码在 URL 锚点、XOR 密码加密）仍可正常打开，已生成的历史链接不受影响。

## 二、本地使用（单机）

直接双击 `index.html` 用浏览器打开即可。

## 三、网络部署（让其他计算机访问）

### 方式 A：双击启动（推荐）
1. 双击 `启动服务.bat`
2. 窗口会打印本机访问地址和局域网访问地址（绿色），例如：
   ```
   本机访问：  http://localhost:8765/
   局域网访问：http://192.168.0.106:8765/
   ```
3. 其他计算机（同一 Wi-Fi / 局域网）在浏览器打开 **局域网访问地址** 即可使用
4. 保持命令行窗口开启，服务才会持续运行；按 `Ctrl+C` 停止

### 防火墙（首次部署）
脚本会**自动尝试**添加 Windows 入站防火墙规则（允许 8765 端口）。若当前账户非管理员，自动添加会失败，此时其他计算机无法访问，请以**管理员身份**打开 PowerShell 执行一次：

```powershell
New-NetFirewallRule -DisplayName '薪资计秒器 Web 服务 (8765)' -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8765 -Profile Any
```

或直接以管理员身份双击 `启动服务.bat`（脚本内含自动添加逻辑）。

### 方式 B：手动命令
```powershell
cd 到本目录
powershell -ExecutionPolicy Bypass -File serve.ps1
```

## 四、技术说明
- `serve.ps1` 使用 `TcpListener` 监听 `0.0.0.0:8765`，**无需管理员权限**即可绑定端口（相比 `HttpListener` 不需要 URL ACL 预留）。
- 仅提供静态文件服务，安全风险低；已做目录穿越防护。
- 端口 `8765` 可在 `serve.ps1` 顶部 `$Port` 修改（需同步修改防火墙规则）。

## 五、数据来源
法定节假日与调休数据来自国务院办公厅官方通知：
- 2026 年：《关于2026年部分节假日安排的通知》（2025-11-04）
- 2025 年：《关于2025年部分节假日安排的通知》（2024-11-12）

仅覆盖 2025、2026 两个完整年度；选择其他年份按纯周末模式估算。
